One-line: the reference card — a finished project, or the ":-)" card inviting the next one.

```jsx
<RefCard title="Tagudskiftning i Gl. Hasseris" meta="Byggeri · Aalborg, 2026" image="assets/images/ref-glhasseris-1.jpg" />
<RefCard smiley title="Dit projekt her?" meta="Vi tager gerne en uforpligtende snak." cta="Kontakt os" />
```

- Three per row, one below 980px. Card sits on --panel, so it reads as a raised surface on the page ground.
- The ":-)" is set in Google Sans Code — the only place mono appears at display size.
